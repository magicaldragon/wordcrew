# Proper nouns, kept out of the vocabulary bank on purpose.
#
# A word game teaches words, not trivia. "France", "Berlin" and "Toyota" carry no
# meaning beyond the name itself, they are never the target of a lesson, and a flashcard
# that asks for the gloss of "Moscow" teaches nothing. So the generator skips every key
# listed here and cefrWordLists.ts no longer carries the same names in its packs.
#
# The line this file draws, because a name-based heuristic does not work: the translator
# renders "Africa" as "Châu Phi", "coast" as "Bờ biển" and "portrait" as "Chân dung" —
# capitalisation says nothing about whether a word is a name. Hand-curated is the only
# reliable filter.
#
#   dropped — countries, capitals and major cities, continents, regions, oceans and
#             mountain ranges, nationalities and language names, religions, people's
#             first and last names, brands and companies, and institution names.
#   kept    — words that are ordinary English despite starting life as a name, so they
#             are NOT listed below: "chile" (a chilli), "jersey" (a shirt), "polish"
#             (to polish), "reunion" (a gathering), "pound" (a unit of weight, and a
#             currency), "turkey" (the bird), "china" is dropped because the pack word
#             is the country, not the porcelain.
#   kept    — calendar, cultural and science vocabulary beginner textbooks teach:
#             "christmas", "easter", "olympics", "saturn". Capitalisation there is
#             orthography, not a quiz on trivia.
#
# One entry per line, lower-case, # starts a comment. The app lower-cases every pasted
# word, so "North America" is listed as "north america".
